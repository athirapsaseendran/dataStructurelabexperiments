## 👩‍💻 About the Repository

Welcome to my **Data Structure Lab Experiments** repository!

This repository contains my Data Structures Laboratory programs implemented using the **C programming language** as part of my Master of Computer Applications (MCA) coursework.

## ⚙️ How to Run the Programs

Follow these steps to compile and execute the C programs on your system.

**Step 1: Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/dataStructurelabexperiments.git
```

**Step 2: Navigate to the project folder**

```bash
cd dataStructurelabexperiments
```

**Step 3: Compile a C program**

For example, to compile the BFS program:

```bash
gcc bfs.c -o bfs
```

**Step 4: Execute the program**

On Windows:

```bash
bfs.exe
```

On Linux/macOS:

```bash
./bfs
```

You can follow the same procedure for the other C programs by replacing the filename.
