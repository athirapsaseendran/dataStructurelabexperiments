# 📚 Data Structure Lab Experiments

Welcome to my **Data Structure Lab Experiments** repository!

This repository contains the programs and practical implementations completed as part of my Data Structure Laboratory during my MCA (Master of Computer Applications) course.

## 🎯 Objectives

- Understand fundamental data structures and their operations.
- Implement data structures using C programming.
- Develop logical thinking and problem-solving skills.
- Explore different algorithms and their applications.

## 🛠️ Technologies Used

- **Programming Language:** C
- **IDE:** Visual Studio Code
- **Compiler:** GCC

## 📂 Experiments

This repository contains implementations of various data structure concepts, including:

- Arrays
- Linked Lists
- Stacks
- Queues
- Searching Techniques
- Sorting Techniques
- Trees
- Binary Search Trees
- B-Trees
- Hashing
- Graphs
- Disjoint Set Operations

*Note: The experiment list will be updated as new programs are added.*

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/datastructure-lab.git
   ```

2. Navigate to the project directory:

   ```bash
   cd datastructure-lab
   ```

3. Compile a C program:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program:

   ```bash
   ./output
   ```
